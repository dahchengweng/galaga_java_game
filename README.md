# Java Galaga

一個使用 Java Swing 製作的簡單 Galaga 風格射擊遊戲。

這個專案主要用來練習 Java 的：

- Swing GUI
- JPanel
- Graphics 2D 繪圖
- Keyboard Focus
- Keyboard Event
- Game Loop
- Collision Detection
- Object-Oriented Programming
- ArrayList
- Timer

## 🎮 遊戲操作

| 按鍵 | 功能 |
|------|------|
| ← | 向左移動 |
| → | 向右移動 |
| ↑ | 發射子彈 |
| R | 遊戲結束後重新開始 |

## 🕹️ 遊戲玩法

玩家控制畫面下方的太空船。

敵人會在畫面上方左右移動，並逐漸向下移動。

使用 ↑ 發射子彈擊落敵人。
